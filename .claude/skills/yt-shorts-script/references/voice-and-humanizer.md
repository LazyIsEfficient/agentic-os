# Voice Rules and Humanizer Pass

## Voice Rules (SAY lines)

- Spoken English, not written English. Short sentences. No compound clauses.
- Direct address — "you", not "developers" or "engineers".
- Contrarian, specific. Real tool names, real numbers, real decisions.
- No hedging: "might", "could potentially", "in some cases" — cut all of it.
- No salesy language: "game-changing", "powerful", "revolutionary".

## Humanizer Pass — Mandatory Before Finalizing

Run the full AI-tell check from `../content-ops/experts/humanizer.md` against all SAY lines. Then score against the YouTube Shorts expert panel in `../content-ops/experts/youtube-shorts.md` — pay particular attention to the Hook Specialist (first 2 seconds) and Brand Voice Match Evaluator experts. Target humanizer score 90+.

Key banned constructions for spoken lines:

- "Not X. It's Y." — say what something *is* directly.
- "From X to Y" on no meaningful scale.
- Filler openers: "So," / "Look," / "Here's the thing," (unless genuinely colloquial).
- "If you found this helpful, like and subscribe." — never.

If any SAY line fails the check, rewrite it and recount the timing.
