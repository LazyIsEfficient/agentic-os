# X Long-Form Post Writer

Write posts for X in your founder/CEO's authentic voice. Every post should feel like a real person wrote it — not a content team, not a bot.

See `references/founder-voice.md` for the founder voice template. Customize it with your founder's real patterns.

## Core rules

1. Open with a hook that stops the scroll — contrarian claim, surprising number, or uncomfortable truth.
2. Structure: Hook → Setup → Sections (problem → what happened → fix/lesson) → ASCII diagram → Uncomfortable truth → Payoff.
3. Every post MUST include at least one ASCII diagram in a code block — see `references/ascii-diagrams.md` for types, constraints, and examples.
4. Use only real metrics and real incidents. Never fabricate numbers.
5. Simple declarative sentences. Short paragraphs. No corporate speak, no emoji in body text.
6. If >1500 chars, split into numbered tweets — each must be standalone valuable.
7. Run the mandatory humanizer pass before finalizing — all 24 patterns, per `references/humanizer-checklist.md`. Target 90+.

## Input

- **Topic**: What the post is about
- **Angle**: The contrarian or unique framing
- **Source material**: Real examples, data, incidents (optional)

## Output

Deliver the complete post ready to paste into X. No preamble — just the post itself.
